## Question

Claude Code Plugin 能否仅包含一个或多个 Skill？是否仍有必要以“只能包含 Skill”区分 Suite 与 Plugin？

## Answer

2026-10-20：回填此前已完成的官方文档核查，非本次新研究。Claude Code 创建教程直接提供单 Skill 插件，组件规范支持多个 Skill；其他组件不是插件成立的前提。

证据、最小目录、宿主范围及本地模型对照见 [研究记录](../../../docs/research/claude-code-skill-only-plugins.md)。本次研究没有运行 Claude Code 实机安装，不能将文档核查视为运行验收。

# 确定草稿、取消、兼容与使用动作

Labels: wayfinder:grilling
Type: grilling
Status: resolved
Assignee: unassigned
Blocked by: 02, 03

## Question

草稿是否自动保存？恢复时如何处理权限变化和并发？取消是否撤销成功操作？旧入口及客户端如何兼容，详情中如何呈现使用方式？

## Answer

2026-11-09：回填本聊天第四轮 Q11–Q14，用户真实答复“按推荐”。

确认自动保存当前发布者填写的信息，保留显式保存，并如实提示未完成上传。继续执行重新检查权限，替换材料重新核对，并发冲突明确提示。取消停止后续操作，已完成内容保留。旧链接准确映射或保留过渡页面，CLI/API 和历史详情继续兼容。详情固定位置提供实际支持的安装、下载、命令或连接配置动作。

行为与验收见 [设计中的 Q11–Q14](../../../docs/unified-publication-design.md#已确认)。

# 统一用户流程，保留领域边界

Labels: wayfinder:grilling
Type: grilling
Status: resolved
Assignee: unassigned
Blocked by: None

## Question

统一是聚合旧入口还是编排完整用户操作？材料类型由谁识别？软件是否并入同一发现页面？

## Answer

2026-11-09：回填本聊天第一轮 Q1–Q3，用户真实答复“按推荐”。

确认统一操作与流程编排，保留领域权限、校验和生命周期；根据材料清单识别类型并供用户核对，仅在不明确时询问；软件并入默认发现和搜索，类型作为筛选，取消顶部独立软件中心入口。

行为与验收见 [设计中的 Q1–Q3](../../../docs/unified-publication-design.md#已确认)，架构取舍见 [ADR-0006](../../../docs/adr/0006-unify-publication-experience-across-domains.md)。
